🚀 AVAILABLE COMMANDS
═══════════════════════════════════════════════════════════════════════════

In VS Code, press Ctrl+Shift+P and type:

1. Agent Bridge: Open Agent Bridge Panel
   └─ Opens interactive webview UI

2. Agent Bridge: Run Agent
   └─ Quick agent executor with dropdown

3. Agent Bridge: Read Workspace Files
   └─ Read files by glob pattern (e.g., src/**/*.ts)

4. Agent Bridge: Write File
   └─ Create or update files in workspace

5. Agent Bridge: Get Available Models
   └─ List AI models

6. Agent Bridge: Get Execution Modes
   └─ List execution modes (agent, autopilot, supervised, etc.)

7. Agent Bridge: Check Health Status
   └─ Verify server connection
