## 🚦 How It Works

```
User clicks "Start Agent"
    ↓
Hook executes agent via API
    ↓
Backend runs agent from .kiro/agents/
    ↓
Output streams back to UI
    ↓
Logs display in real-time with colors
    ↓
Status updates as agent progresses
    ↓
Next agent unlocks when previous completes
```
